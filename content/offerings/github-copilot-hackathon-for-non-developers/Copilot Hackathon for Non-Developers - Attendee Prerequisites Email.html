Install VS Code and Git

Install the GitHub Copilot app

Both are free. Visual Studio Code from code.visualstudio.com, Git from git-scm.com. Install Git first: the GitHub Copilot app will not start without it. Accept the default options in both installers.

Get Visual Studio Code

Download it for Windows or macOS, sign in with the account from step one and leave it signed in. This is the app you will build with all day, so it is worth opening once before you arrive.

AND BRING ONE IDEA

Something your team still does by hand

Think of one thing your team does with a spreadsheet, a shared inbox or a form that somebody re-types: a tracker, a checklist, a small lookup, a request form, a rota. The best hackathon ideas are boring, specific and yours.

You do not need to design it or write anything down. Bring the problem. Your team lead will help you cut it into something that can be finished, reviewed and published inside a single day.

PLEASE READ · GROUND RULES

The hackathon runs in a temporary GitHub organisation that Microsoft and GitHub set up and then delete. Use sample or made-up data only — no customer data, no personal data, nothing confidential. What you build on the day is a prototype, not a production system, and we will show you how to export it before the environment closes.
